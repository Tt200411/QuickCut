## 审核发现并补修

1. **模型 HTTP 响应中断导致整份草案失败。** `response.read()` 的 `IncompleteRead`、无效 HTTP 状态，以及 HTTP 错误正文的中断都可能逃过原先的异常处理。现在将这些传输失败归档，保留当前旁白及合法选镜，停止重试；必要证据写盘失败仍明确停止。测试覆盖正常超时、部分响应、无效状态和错误响应正文中断。
2. **旧字数参考或极短预算漏报粗估超时。** 旧草案保留的字数参考可能高于新估算公式，最小字数参考也可能超过极短画面预算。现在同时检查字数参考和粗估时长，提示如实展示计划与粗估秒数，仍不把估算变成硬门禁，也不改写冻结输入。
