## Use the deployment

See [E's installation and inference commands](E-local-voice.md#indextts2-narration). From the repository root, use `scripts/indextts2_python.sh` to select the isolated environment. The general project `.venv` is a separate Python 3.14 environment and does not contain the IndexTTS2 runtime.

The countryside entry point now defaults to IndexTTS2; `--system-voice` explicitly selects the comparison path. Both demos accept `--voice-config`. Model/config/reference failures stop execution. The configured doctor checks the chosen model, device and actual reference WAVs, including cue overrides, and does not mistake an installed `say` executable for a working model.

To replace the test reference, update `reference_audio` in the voice configuration to an existing WAV. Its content hash is included in cache identity, so changed reference audio invalidates the corresponding narration cache.
