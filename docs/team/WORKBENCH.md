# QuickCut 本地网页工作台

当前入口为 HTML 工作台，使用新多素材 A–F 契约。单元测试中的替身与合成音调保留用于离线回归；工作台不提供 fixture、规则选镜、颜色检索或系统语音降级选项。

## 启动与使用

在本机双击仓库根的 `QuickCut.command`，或者运行：

```sh
./scripts/quickcut_web.sh
```

浏览器访问 `http://127.0.0.1:8765`。也可运行 `python -m quickcut.workbench --open`；`python -m quickcut.ui` 已改为启动此工作台。旧 `build_demo()` 和旧单视频 CLI/API 作为兼容接口保留，不是新工作台的内部路径。

1. 导入 1–12 个真实视频，填写剪辑要求、目标时长和素材来源。可同时上传参考 WAV；不上传则使用页面标出的默认音色。
2. A 分析媒体并运行 Whisper；B 运行中文视觉检索；C 用 Qwen 查看真实接触表并生成选镜和旁白草案。
3. 预览候选片段，确认或调整入出点、修改旁白。确认者与时间、文本哈希、边界方法随版本留档。
4. E 使用已部署 IndexTTS2 和参考音频生成 WAV；D 对齐四轨，必要时最多请求两轮 fit；F 生成 MP4 和可编辑剪映包。
5. 下载视频/工程。勾选自动打开剪映后，服务会安装一个新的 QuickCut 草稿并启动剪映。

Qwen 的候选 ID、理由和角色结构必须合法；结构错误最多追加一次真实模型修复，仍不合法就明确失败。合法选镜之后，旁白内容问题或超出时长粗估可触发最多两次独立重写，只改旁白，不改候选 ID、顺序、理由和角色；缺少已选镜头图片时不进行无图改写。网络失败保留当前文案；必要证据归档失败则明确停止，不静默接受。生成 Schema 不以 `maxLength` 限制旁白，不自动截字或补句号。

草案的 `narration_review` 区分内容 `warnings` 与时长 `advisories`：空白、非中文、检测到的残句或超过 160 总字符编辑安全上限需要修改；超出朗读字数粗估只显示“时长待实测”，完整句可确认后交给 E 测量。标点完整不等于语义完整，规则检查不能代替人工核对画面与文案。当前 2.5 字/秒加 0.8 秒是未按音色校准的保守估算，不是字幕行长或配音硬上限；此前上游的 4.2 字/秒乘 90%（5 秒约 18 字）同样不能代替真实测时。若完整音频不能适配，返回 `VOICE_NEEDS_RETIME`，不裁尾；人工冻结的镜头边界不会自动越界延长。用户或助手的确认分别留证，原始模型旁白与选镜保持原样，重写另行归档。

**若剪映正在运行，生成不会丢失。** 为保护当前编辑状态，工作台提示先保存并完全退出剪映，再点击“打开剪映”。安装器备份草稿注册表，只增加新草稿。当前支持 macOS 剪映专业版 6.1.0/build 309；启动应用与已经打开具体工程的实机验收分别记录。

## 模型环境

模型依次运行，ASR、B、Qwen 请求和 TTS 各用可停止的独立进程；Qwen 在 TTS 前卸载。跨工作台实例的计算锁避免同机并发加载这些模型。

| 模块 | 当前真实路径 |
| --- | --- |
| A | `.venv/bin/python`；faster-whisper small，CPU/int8，保留原声范围与待复核状态 |
| B | `.venv-vision/bin/python`；OpenCLIP nllb-clip-base，固定 checkpoint 与 tokenizer |
| C | 本机 Ollama `qwen2.5vl:3b`；显式上下文长度、单张编号接触表、原始请求/响应归档 |
| E | `outputs/indextts2-runtime/upstream/.venv/bin/python`；模型和参考声音配置见 `examples/voice_package/indextts2.config.json` |
| F | FFmpeg/ffprobe、本机剪映 6.1.0 |

环境配置可用 `QUICKCUT_PIPELINE_PYTHON`、`QUICKCUT_VISION_PYTHON`、`QUICKCUT_TTS_PYTHON`、`QUICKCUT_VOICE_CONFIG`、`QUICKCUT_VLM_MODEL`、`QUICKCUT_OLLAMA_URL`、`QUICKCUT_ASR_MODEL` 指定。服务只监听本机。模型请求绕过系统 HTTP 代理，生产推理禁止临时联网下载权重；缺少文件会明确停止。

B 固定环境从 `outputs/vision-runtime/deployment-manifest.json` 读取 checkpoint/tokenizer 的真实路径，不能被旧脚本的 `pretrained=v1` 默认值覆盖。部署文件就绪仅代表安装检查通过，不代表模型效果已经验收。

IndexTTS2 的输入包括已批准文本和参考音频。工作台接收 1–30 秒、最大 20 MB、完整且有有效声音的 PCM16 WAV；每个新任务保存自己的 `reference/voice.wav`、`voice-config.json` 和原始来源/SHA-256，预检和合成都读取该任务配置。修改默认音色不会改变已经建立的任务；逐句参考覆盖也统一到本次选定的参考音频，逐句 seed 保留。声音缓存包含参考音频字节哈希，换音色不能误用旧 WAV。

默认参考为用户选择的 `男声.wav`（24 kHz、单声道、3.32 秒）。根据用户本次共享要求，原始 `ref_audio.zip` 和三份 WAV 一同保存在 `materials/reference-audio/20261117/`；默认声音配置直接引用其中的 `男声.wav`。新克隆仓库需先安装 Git LFS 并在仓库根运行 `git lfs pull`，取得真实音频和共享交付媒体，不能把 LFS 指针文件当成 WAV。也可在页面上传其他有效参考 WAV，仅用于新建任务。

共享参考音频不包含本地模型环境。新机器仍需运行 `python3 scripts/setup_indextts2.py` 和 `python3 scripts/setup_vision.py` 准备固定版本的模型与环境；安装脚本不会替换参考 WAV。部署清单包含本机路径，应由目标机器重新生成，归档中的旧清单仅作为验收证据。

## 失败恢复与版本

- A/B/C 运行或选镜结构失败：保留素材并重新分析；A 会验证媒体及缓存，B 只有输入内容和实现指纹都一致才复用之前的真实模型结果。草稿旁白的内容警告应在方案中修改和确认，无需为此重新分析。
- 配音或导出失败：返回已完成草案，修改文字/边界后重新确认；不用重新上传和规划。每次确认生成新的 StoryPlan、VoicePackage 和 Timeline 版本。
- 超预算不会截断发音。两轮后仍不适配会返回错误、受影响句子和完整适配记录。
- 缺图、编码/评分错误与“正常推理但没有匹配”是不同状态，不会以无匹配掩盖运行故障。
- 关闭服务会取消排队工作并终止它启动的模型进程。已经开始的文件导出会收尾保存，不会在关闭后继续自动打开编辑器。

每次确认以 `revisions/r<attempt>/` 保存独立修订，已有目录不能覆盖。成功与失败都保留批准记录、StoryPlan、边界、声音配置、测量包和每轮适配的 pending/request/reply；顶层常用 JSON 保持现有界面兼容，历史应按报告的 `revision_archive` 查找。D 在启动适配子进程之前就保存 pending/request，记录写入失败会停止派发。下一次生成不会覆盖上一次失败轮的唯一证据。

适配阶段取消保留 `CANCELLED`，任务显示 `interrupted`。服务重启后，只要已经形成有效草案，就能返回方案调整后再次确认，无需为了 E/F 失败重复 A/B/C。重新生成后打开剪映会核对当前导出修订；新修订安装到独立的 `QuickCut-<job>-r<attempt>` 草稿，避免打开此前版本或覆盖用户编辑。

对于原视频已有烧录字幕的情况，可将新字幕放到顶部。位置随任务 settings 留档；工作台在冻结导出前保存 D 原始时间线和显示策略的前后哈希，只改变字幕显示位置，不改变 D/E 的时间安排或 fit 回执。

## 证据与范围

每个任务位于 `outputs/workbench/<job_id>/`：原始上传、A 清单、检索请求/候选、Qwen 请求证据、未批准草案、确认记录、边界记录、E 实测包、适配往返、D 时间线、F 包和阶段日志。

`run-report.json` 记录实际后端、文档版本、实际成片时长、下载文件和剪映启动结果；失败保留 `error.json`。首轮失败与重试的模型证据按请求内容分别保存。自动验收使用 `assistant_review` 标记，不冒充真人审阅。

当前 D 支持真实源区间的人工确认和修改，验证预算、来源及音轨联动；这不等同于已实现动作理解模型的自动精剪。A 的 ASR 结果仍需要内容复核；模型看图、合法 JSON 和完整解码均不替代主观听审。音乐、转场、变速、复杂效果和其他剪映版本不在本版导出能力内。

本轮运行、失败修复和原生编辑器证据见 [独立验收记录](WORKBENCH-acceptance-20261116.md)；历史 11 月 15 日系统语音包及 IndexTTS 单模块结果各保留原范围。
